# SAC-7 Sprint 2 Extra Challenge

This project implements the Sprint 2 priority extra challenge.

## Requirements covered

- Every task card contains a Priority dropdown.
- Priority options are LOW, MEDIUM and URGENT.
- LOW keeps the default card background.
- MEDIUM keeps the default card background.
- URGENT changes the task card background to red/light red immediately.
- Priority is stored on the Task object and updated through TaskManager.

## Run

Open `index.html` in a browser.
